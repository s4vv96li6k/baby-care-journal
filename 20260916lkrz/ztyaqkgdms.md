日常生活中，有很多人会补充叶酸等营养物质。对于叶酸，你了解多少呢？不妨进行以下小测试，帮助您提高对叶酸的认识吧！

 

1、叶酸是一种：

A  维生素B

B  维生素E

C  脂肪酸

D  矿物质

 

答：正确答案：A

 

2、叶酸缺乏可能导致：

A  高同型半胱氨酸血症

B  巨幼红细胞性贫血

C  胎儿神经管畸形

D  以上所有

 

答：正确答案：D

 

3、食品中叶酸含量达到多少可称为“高或富含叶酸”？

A叶酸含量≥ 180 μgDFE/100g固体

B 叶酸含量≥ 120 μgDFE/100g固体

C 叶酸含量≥ 90 μgDFE/100g固体

D 叶酸含量≥ 60 μgDFE/100g固体

 

（*DFE：膳食叶酸当量（dietary folate equivalent））

 

答：正确答案：B

 

4、你打算从你的食物中得到更多的叶酸,下列哪些食物是最好选择? (多选)

 

A鸡肝

B大豆粉

C菠菜

D人奶

E肉类

 

答：正确答案：ABC

 

5、如果你打算增加叶酸吸收量, 下列哪种选择是最好的?

 

A蔓越橘汁

B橙汁

C苹果汁

D柠檬汁

答：正确答案：B

 

6、关于叶酸，以下哪种说法是正确的？

A 天然叶酸和合成叶酸在体内的利用率相同

B 营养素补充剂中的叶酸是天然叶酸

C 天然食物中的叶酸结构不稳定

D 人体可以合成叶酸

 

答：正确答案：C

 

7、以下除外( )都是确保每天摄取足够叶酸的方法：

A 每天服用400微克（mcg）的叶酸

B 吃一碗每日摄入叶酸量可达100％的麦片

C 服用叶酸补充剂

D 吃一盘西兰花

 

答：正确答案：D

 

8、脊柱裂和脑裂：

A 是神经管缺陷

B 是最常见的可预防的先天缺陷

C 如果女性每天服用叶酸补充剂，风险可以降低

D以上所有

 

答：正确答案：D

 

9、在我国，新生儿神经管缺陷的发生率大约为：

A  1.2/十万

B  1.2/万

C  1.2/百万

D  1.2/千

 

答：正确答案：B

 

10、 一般情况下，大多数备孕期的女性每天需要补充叶酸的量为：

A 每日400 μg

B 每日400 mg

C 每日200 mg

D 每日200 μg

 

答：正确答案：A

 

11、为了预防新生儿神经管缺陷，应从什么时候开始补充叶酸？

A 发现怀孕之后

B进行第一次孕前检查之后

C 可能妊娠或孕前至少3个月开始

D 妊娠中晚期

 

答：正确答案：C

A 脑卒中

B 高血压

C 糖尿病并发症

D 以上全部

A 每日400 μg

B 每日800 μg

C 每日400 mg

D 每日800 mg
